## Templates

| Template | Contents |
| --- | --- |
| [BASIC](templates/BASIC.md) | Project overview, setup, usage, roadmap, contributions, contributors, contact, acknowledgements, and license. |

The BASIC template includes a centered header, repository badges, an expandable table of contents, and linked images for contributors, contact, and acknowledgements.

[Back to top](#readme-top)

## Usage

1. Clone this repository.

   ```sh
   git clone https://github.com/donaldturinglee/awesome-readme.git
   cd awesome-readme
   ```

2. Copy a template to your project's root directory as `README.md`.

   ```sh
   cp templates/BASIC.md ../your-project/README.md
   ```

3. Customize the template for your project.

   | Value | Replace with |
   | --- | --- |
   | `Title`, `Description` | Your project name and a short description. |
   | `github_username`, `repo_name` | The GitHub owner and repository name. |
   | `documentation_url`, `demo_url` | Links to your documentation and demo. |
   | `your_email` | Your contact email address. |
   | `resource_name`, `resource_url`, `resource_image_url` | Names, links, and images for acknowledgements. |
   | `project_license` | The license used by your project. |

   Fill in the remaining technology, command, configuration, and feature placeholders. Keep the sections relevant to your project and check the links and images in a Markdown preview.
